# CI/CD for Functions Using Python

Starter files for the Azure Functions CI/CD project.

The archive includes a compiled `submitter` binary. Keep it in your private GitHub repository so it is available when you clone the project later.

## Next steps

1. Create a private GitHub repository and push these files (including `submitter`).
2. In the project directory, initialize an Azure Functions Python project (`func init .`) if you have not already.
3. Implement `analyze_number` in `function_app.py`.
